# Project Requirements

## Functional Requirements

- FR01: The device must generate a sine wave.
- FR02: The device must generate a square wave.
- FR03: The device must generate a triangle wave.
- FR04: The frequency must be adjustable.
- FR05: The device must be controllable via WiFi.
- FR06: The RC filter must reduce unwanted high-frequency components.

## Technical Requirements

- TR01: ESP32-WROOM-32 as microcontroller.
- TR02: Integrated 8-bit DAC for analog signal generation.
- TR03: RC low-pass filter.
- TR04: Custom PCB designed in KiCad.
- TR05: Measurements using an oscilloscope.
